HTMLDOC 1.9.25 is a bug fix release.  Changes include:

- Updated the maximum length of "data:" URLs to 32k (Issue #573)
- Fixed the Windows installer metadata that was preventing upgrades from prior releases (Issue #572)
- Fixed an issue in the source code that prevented GCC from successfully building with LTO optimization settings (Issue #576)

Binaries are available from Github for Windows 10+ and macOS 11+, and through the Snapcraft store for Linux.

Enjoy!
